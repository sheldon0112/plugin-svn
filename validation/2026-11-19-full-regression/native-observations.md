# 本轮 macOS 原生操作证据

日期：2026-11-19；CC GUI 1.2.5；方式：cua_repl 原生 AX 与截图。以下是本轮现场观察摘录，历史验证文件不作为本轮执行证据。截图在当前聊天工具记录中，未冒充独立截图文件。

- 初始详情：`v0.2.0 完整插件 已安装`；正文同时显示 `当前版本：0.1.9`、`当前兼容目标仅为 Windows 11`。
- 工作区：`host-wc`；`SVN 版本控制 r7`；`工作副本没有本地更改`。
- 历史：`r8 CC GUI 本机临时仓库发布验证`，以及 r5、r4、r3、r2、r1。
- 诊断：`连接成功；认证与代理由本机 SVN 配置处理`；等待执行按钮恢复后 Escape 关闭，弹窗消失。
- 复制：点击 r8 的「复制版本」，在关键词字段粘贴，AX 显示 `Value: 8`；随后清空输入。
- 视觉：110% 截图中文与顶部操作可读；恢复 100%；r8 差异显示 `host-proof.txt`、`+1 -0` 与中文内容；换行按钮切换选中态。
- 卸载：确认框 `其保存的数据将保留 30 天`；确认后 SVN 侧栏入口和插件页签消失。未验证等待 30 天后的物理数据删除。
- 重装：真实 macOS Open 目录选择器显示 `选择插件目录（含 manifest.json）`；选择当前插件目录后入口恢复。
- 升级：下载个人官方 Release 0.1.8 的 main.js/manifest.json，目录安装后已安装列表显示 `SVN 管理面板 v0.1.8`；再安装当前原始目录，列表显示 `SVN 管理面板 v0.2.0`，启用开关 on。未修改任何产品文件或 README。
- 停用：开关 off 后 SVN 侧栏和页签消失；启用后入口恢复。最终重新打开 SVN 面板，host-wc 信息可读且无本地更改，当前版本恢复为 0.2.0、启用状态。
- 真实市场列表显示 v0.1.8；本轮跨版本升级是从本地目录执行，不代表市场 0.2.0 更新已验收。
