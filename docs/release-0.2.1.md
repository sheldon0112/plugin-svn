# v0.2.1 发布说明

## 变更

- 剪贴板写入全部失败时给出可访问的失败反馈（D-01）：现代 `writeText` 被拒绝且回退 `execCommand` 失败时，复制版本、差异与脱敏操作记录三个入口统一提示错误，并清理临时输入框。
- Windows 检出目标统一分隔符并追加末尾 `/`（L-02）：避免 `space @wc` 这类目录名进入客户端 `@` 拆分路径导致实际目录名变形；登记与返回仍为原始目录。
- `/state` 在 SVN 报告的 `wcroot-abspath` 与登记路径指向同一目录时保留登记原路径表示（F-01）：Windows 客户端返回的正斜杠形式不再与登记路径显示不一致；嵌套/切换工作副本的判定行为不变。
- 新增 `clipboard-fix`、`edge-coverage`、`full-coverage`、`windows-defects` 测试套件与 `windows-defects` 取证工作流；默认回归纳入剪贴板用例与 `/state` 登记路径一致性断言。

## 验证与已知限制

- 本地默认套件两轮 7 通过、1 TODO、0 失败；边界检查 24/24；Windows 取证脚本通过。
- 2026-11-22 真实 Windows 真机回归：修复前 15 例 full-coverage 失败经 main 同环境对照确认为环境暴露而非本插件缺陷；修复后 `/state` 用例转通过。
- Windows 中文命令行参数问题（L-01）仍未解决，故障位于 SlikSVN 1.14.5 客户端的代码页转换；TortoiseSVN 1.14.2 实测中文目录检出成功，客户端差异已在取证记录中归档。
- 全量 QA 套件的 Windows 模拟配置以 macOS 宿主为设计环境；真实 Windows 宿主上 12 例因测试装置的输出改写假设与真实客户端输出不匹配而失败，经基线对照确认与插件无关。
- README 中版本与支持范围文案未随版本更新（既有约束），实际版本以 manifest.json 为准。
- 真实 UNC 共享、NTFS ACL、长路径 I/O、系统剪贴板策略与 DPI 视觉组合仍按既有未覆盖项补测。

## 安装及回滚

通过插件市场更新，或下载 Release 中的 main.js 与 manifest.json，放在同一目录后从 CC GUI 插件页安装。重装同一 ID 会热重载。需要回滚时安装此前已验证版本；卸载通过插件页进行，宿主的数据保留规则不变。

详细记录见 [缺陷修复与验证记录](defect-fixes-2026-11-19.md) 与 [2026-11-22 回归证据](../validation/2026-11-22-windows-regression/)。
