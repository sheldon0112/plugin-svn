# v0.2.0 发布说明

## 变更

- 适配 Windows 盘符、UNC、分隔符、路径大小写比较和工作副本名称。
- 完善 Windows 保留名称、控制字符及路径越界校验。
- 统一 Windows 等价路径的写操作互斥键，并适配 UNC 空设备。
- 修复追加 svn:ignore 规则时混合 CRLF／LF 导致 E135000 的问题。
- 增加 macOS／Windows 各两轮 CI 回归，以及安装／启动／卸载模拟。

## 验证与已知限制

- 已有最终功能 CI：macOS 两轮各 7 项通过；Windows Server 2025 两轮各 5 项通过、2 项 TODO 实测失败。
- Windows 中文参数与检出目录中 @ 前空格问题仍未解决，不能据工作流成功认定 Windows 全量兼容。
- 这些是已观察到的故障；实际可执行文件解析、代码页、目标程序内部转换尚未完整取证，不能把根因视为已确认。扩展测试的模拟桥接也尚未透传插件 env，后续应补齐与真实宿主一致的环境对照。
- Windows 11 真实 CC GUI 安装卸载、UNC 网络读写、长路径、ACL、非 UTF-8 输出及安全软件干扰仍需补测。

详细记录见 [兼容改造与回归记录](platform-compatibility.md)。

## 安装及回滚

通过插件市场更新，或下载 Release 中的 main.js 与 manifest.json，放在同一目录后从 CC GUI 插件页安装。重装同一 ID 会热重载。需要回滚时安装此前已验证版本；卸载通过插件页进行，宿主的数据保留规则不变。
