# 0.1.9 交付说明

## 变更

- 写操作失败后核对工作副本状态；读取与写入分别设置超时，显示耗时及恢复指引。
- 检查宿主输出上限，拒绝将可能截断的差异或 XML 作为完整结果。
- 增加检出及工作区登记、合并预演和执行、分支／标签创建、属性读写及忽略规则维护。
- 增加有界、脱敏的会话操作记录，调整窄面板布局。
- 增加真实临时 SVN 仓库测试及失败恢复、语言切换回归。

## 当前兼容范围

当前兼容工作仅面向 Windows 11。其他系统和 Windows 版本均为本轮不处理、后续评估；保留已有实现，不扩大本轮范围。

Windows 11 的具体 Build、架构、宿主与 SVN 组合尚待真实环境认证。本版本代码提交不代表 Windows 11 验收通过；现有测试仍有需要适配 Windows 文件命名规则的夹具，不能直接作为 Windows 11 通过证据。

## 已知边界

- 工作副本路径包含 @ 时合并明确拒绝。
- 当前宿主执行接口不支持运行中取消，单路输出上限为 64 KiB；达到上限时提示内容可能不完整。
- 认证及代理沿用本机 SVN 配置；真实企业认证、代理及证书环境需另行验证。
- 创建分支／标签的目标存在性检查与实际复制之间仍有并发窗口。

## 发布流程

现有发布工作流仅匹配形如 0.1.9 的标签推送，不由 main 分支推送触发。工作流校验标签与 manifest.version 一致，并发布 main.js、manifest.json 及 checksums.txt；本次保留该工作流原样。

本机安装记录和测试现场含绝对路径，单独保留，不随公开源码提交。安装方式沿用 README 中的宿主本地目录安装入口。
