# SVN 管理面板

用于 CC GUI 的本地 SVN 插件。点击左侧「SVN 管理面板」可打开主面板，通过顶部的「工作区」下拉框选择在 CC GUI 中登记的 SVN 工作区。

## 初始版本 v0.1.5

- **更改**：查看本地变更，按状态或路径筛选，查看差异和逐行溯源。对比服务器后可在文件行看到远端变更。
- **历史**：按作者、关键词、路径或日期查询，每次加载 20 条修订摘要。选中修订后再读取改动路径，可查看整版或单个文件的差异。
- **工作副本操作**：更新、清理锁、纳入版本控制、还原、删除、解决冲突和提交所选变更。支持内容、属性和树冲突的识别。

## 常用操作

- **冲突工作台**：点「冲突」，或者在「更改」中右键冲突项。更新检测到冲突后会直接进入工作台。可以逐项查看工作副本差异和传入的文本改动，再确认解决。属性和树冲突请先在工作副本手工处理，再保留当前状态。
- **加入忽略规则**：在「更改」中右键未纳入版本控制的路径，选择「加入忽略规则」。规则追加到父目录的 `svn:ignore`，提交该目录的属性变更后团队成员才会收到规则。
- **文件锁**：点顶部「文件锁」输入文件相对工作副本根目录的路径，也可从更改列表右键查询。查询会显示仓库锁的持有人。当前工作副本持有有效锁时，可从同一入口解锁。
- **切换分支／标签**：点顶部「切换分支／标签」，确认当前路径，再输入目标仓库相对路径，例如 `^/trunk`、`^/branches/release` 或 `^/tags/v1`。请先处理本地变更和工作副本持有的文件锁。切换会刷新状态和历史。

面板会随 CC GUI「通用设置」中的浅色、深色或跟随系统实时更新。

## 安装与更新

1. 确认本机已安装 Subversion 命令行客户端，可用 `svn --version` 检查。
2. 将本仓库克隆或下载到本地。在 CC GUI 打开「插件 → 从本地目录安装」，选择包含 `manifest.json` 的目录。
3. 点击左侧「SVN 管理面板」，选择 SVN 工作区。安装新版时重新选择新版目录即可更新，也可在插件页卸载。

插件 ID 为 `ccgui-svn`。插件读取 CC GUI 工作区列表，并通过宿主调用本机 `svn`。已有 SVN 凭据由本机 SVN 客户端处理。

历史关键词匹配提交说明和作者，文件路径使用「限定路径」筛选。单条修订的改动路径过多时，详情可能超过宿主的命令输出上限。

## 回归测试

在插件目录执行 `npm ci --prefix test` 和 `npm test --prefix test`。需要 Node.js 22.12 或 24 以上版本，以及 `svn`、`svnadmin`。测试使用模拟的 CC GUI 宿主和自动清理的本地 SVN 仓库。
