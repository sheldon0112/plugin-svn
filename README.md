# SVN 管理面板 · CC GUI

[简体中文](README.md) | [English](README.en.md)

在 CC GUI 中管理本机 Subversion 工作副本：查看变更、浏览历史、比较差异、逐行溯源，以及处理提交和冲突。

- **个人仓库**：[sheldon0112/plugin-svn](https://github.com/sheldon0112/plugin-svn)
- **作者**：AnnoDomini
- **当前版本**：`0.1.8`
- **插件 ID**：`ccgui-svn`
- **最低宿主版本**：CC GUI `1.2.4`，插件 SDK `^0.3`
- **许可证**：[MIT](LICENSE)

## 功能

| 功能 | 说明 |
| --- | --- |
| 工作区选择 | 从 CC GUI 已登记的工作区中选择本机 SVN 工作副本 |
| 本地变更 | 按状态和路径筛选，查看内容及属性变更，勾选操作路径 |
| 服务器对比 | 通过 `svn status -u` 查询远端更新，在文件行显示远端状态 |
| 差异预览 | 查看工作副本、整条修订或单个文件的差异，支持换行与复制 |
| 历史查询 | 按作者、关键词、限定路径和日期筛选，每次加载 20 条修订摘要，按需读取改动路径 |
| 逐行溯源 | 查看仓库版本中每行的修订和作者，并跳转查看修订差异 |
| 工作副本操作 | 更新、清理、纳入版本控制、还原、删除和提交所选变更 |
| 冲突工作台 | 识别内容、属性和树冲突，查看工作副本及传入文本改动，确认解决方式 |
| 忽略规则 | 为未纳入版本控制的路径追加父目录的 `svn:ignore` 规则 |
| 文件锁 | 查询仓库文件锁、锁定文件、释放当前工作副本持有的有效锁 |
| 分支与标签 | 将当前工作副本切换到指定的仓库相对路径 |
| 语言与主题 | 简体中文、英文；跟随 CC GUI 的语言及浅色、深色或系统主题设置 |

## 安装

### 前置条件

1. 安装 CC GUI `1.2.4` 或更新版本。
2. 安装 Subversion 命令行客户端，确保 CC GUI 能找到 `svn`：

   ```bash
   svn --version
   ```

3. 准备已检出的本机 SVN 工作副本，并在 CC GUI 中打开或登记该目录。仓库认证由本机 SVN 客户端处理；建议先在终端确认该工作副本可以正常访问仓库。

### 从本地目录安装

```bash
git clone https://github.com/sheldon0112/plugin-svn.git
```

也可从仓库页面下载 ZIP 并解压。

1. 打开 CC GUI 侧边栏「插件」→「从本地目录安装」。
2. 选择克隆或解压后的插件目录，即同时包含 `manifest.json` 和 `main.js` 的那一层。
3. 查看并按宿主提示授予插件所需权限。
4. 点击左侧「SVN 管理面板」，在顶部「工作区」下拉框中选择 SVN 工作副本。

插件是自包含的单文件 ESM，安装使用无需执行 `npm install` 或构建。

### 更新与卸载

- **更新**：获取新版文件后，再次通过「从本地目录安装」选择插件目录。同一插件 ID 会覆盖并热重载，无需重启 CC GUI。
- **卸载**：在 CC GUI 插件页卸载；宿主会保留插件数据 30 天。

## 使用指南

### 查看变更并提交

1. 在「更改」中刷新状态，按状态或路径过滤文件。
2. 点击文件查看差异，或右键查看文件历史、逐行溯源等操作。
3. 新文件先「纳入版本控制」，再勾选要提交的变更。
4. 点击「提交」，核对操作路径，填写提交信息并确认；提交窗口支持 `Ctrl+Enter`。

筛选后，已选但不可见的路径会计入选择提示。提交前请核对确认窗口中的路径。还原会丢弃未提交的本地修改；删除目录会包含其子项，删除操作提交后才会反映到仓库。

「对比服务器」用于读取远端状态，不会将工作副本更新到新版本。需要拉取内容时使用「更新」。

### 查询历史与溯源

在「历史」中设置作者、关键词、限定路径或日期范围，点击「查询」。关键词匹配提交说明和作者；按文件或目录查询请使用「限定路径」。点击「加载更早的提交」继续翻页。

选中修订后读取其改动路径，可查看整版或单文件差异。逐行溯源读取仓库版本，不包含本地未提交的改动。

### 处理冲突

点击「冲突」，或右键冲突项进入工作台。更新发现冲突时也会直接进入工作台。

逐项查看工作副本差异和传入文本改动，再选择解决方式。属性和树冲突应先在工作副本中手工处理，再选择「已手工处理，保留当前状态」。标记解决后，按需要提交处理结果。

### 添加忽略规则

在「更改」中右键未纳入版本控制的路径，选择「加入忽略规则」。规则追加到父目录的 `svn:ignore` 属性；提交该目录的属性变更后，团队成员才能收到规则。

### 管理文件锁

点击顶部「文件锁」并输入相对工作副本根目录的文件路径，也可从更改列表右键查询。查询会显示仓库锁持有人，可锁定文件；当前工作副本持有有效锁时可解锁。

「清理锁」执行的是 `svn cleanup`，用于处理工作副本锁定或未完成的操作，与释放仓库文件锁不同。

### 切换分支或标签

点击「切换分支／标签」，确认当前路径，输入仓库相对路径，例如：

```text
^/trunk
^/branches/release
^/tags/v1.0
```

切换前需处理本地变更、未纳入版本控制的文件、工作副本持有的文件锁，以及已单独切换的子路径。切换会刷新状态和历史。当前实现不支持工作副本根目录名称包含 `@` 的切换操作，请先重命名该目录。

## 权限与数据

| 权限 | 用途 |
| --- | --- |
| `ui:sidebar-entry` | 注册侧边栏入口 |
| `ui:center-tab` | 打开主面板页签 |
| `host:workspace` | 读取 CC GUI 工作区列表 |
| `theme` | 注入面板样式 |
| `exec:svn` | 通过宿主执行本机 `svn` 命令 |
| `i18n` | 注册界面语言资源 |

插件没有独立的上传服务，仓库访问由本机 SVN 客户端发起，已有 SVN 凭据由该客户端处理。提交、锁定、解锁等操作会按 SVN 命令的行为访问或修改仓库。

## 限制与故障排查

| 现象 | 检查与处理 |
| --- | --- |
| 安装失败或入口未显示 | 检查 CC GUI 版本、所选目录及插件页中的权限或加载错误提示 |
| 找不到 `svn` | 确认命令行客户端已安装，且 CC GUI 进程能够找到该可执行文件 |
| 没有可用工作副本 | 在 CC GUI 中打开或登记本机 SVN 工作副本；可在该目录执行 `svn info` 检查 |
| 认证或仓库连接失败 | 在终端对同一工作副本执行 `svn info`、`svn status -u`，检查认证、网络及仓库权限 |
| 工作副本被锁定 | 确认没有其他 SVN 操作正在运行，再使用「清理锁」 |
| 历史详情无法加载 | 单条修订的改动路径过多时，输出可能超过 CC GUI 的命令输出上限 |
| 二进制文件无法显示文本差异 | 当前差异视图用于文本，二进制文件会显示相应提示 |
| 差异显示被截断 | 界面只渲染部分行，可尝试复制差异；可用内容仍受宿主输出上限约束 |

## 开发与验证

### 目录结构

```text
plugin-svn/
├── manifest.json       # 插件信息、兼容版本与权限
├── main.js             # 自包含 ESM 入口、界面与 SVN 操作
├── README.md           # 中文说明
├── README.en.md        # 英文说明
├── LICENSE
└── test/
    ├── package.json
    ├── package-lock.json
    └── regression.mjs  # 模拟宿主与本地 SVN 仓库回归测试
```

### 回归测试

需要 Node.js `22.12+`（22.x）或 `24+`，以及 `npm`、`svn` 和 `svnadmin`。在仓库根目录执行：

```bash
npm ci --prefix test
npm test --prefix test
```

测试使用模拟的 CC GUI 宿主和临时本地 SVN 仓库，结束后清理临时仓库。测试中的提交调用使用模拟结果，因此仍需在真实 CC GUI 中验证实际提交及宿主集成。

修改插件后，重新从本地目录安装，在真实 CC GUI 中检查工作区选择、语言、主题及相关 SVN 操作。
